# Manuscript supplementary tables S1–S27

This directory is the current publication-facing supplementary-table package for Supplementary Sections S1–S8. Table numbering is global across the supplement. Every table is a selection, reordering, or serialization of frozen evidence; no scientific statistic, feature, rank, graph, seed, or model output was recomputed.

Each table is provided as CSV, structured JSON, and LaTeX. `supplementary_table_index.json` and `.csv` record the title, section, frozen private-project source artifacts, and provenance caveat for every table. Source paths are repository-relative and contain no private filesystem locations.

The earlier five-table frozen results package remains in `../tables/` for release reproducibility. It is not the numbering authority for this manuscript supplement; this directory is the current S1–S27 authority.

Rank 1 denotes the most unusual placement. Candidate tables describe frozen inspection cases, not confirmed anomalies. The package makes no cross-mission or cross-class validation claim.
