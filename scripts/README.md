# Reproduction entry points

The repository provides three public commands:

- `reproduce_pipeline.py` validates user-supplied light curves and runs the public feature pipeline subject to the documented operational-context boundary.
- `reproduce_results.py` reproduces frozen Level 2 artifacts or validates Level 3 representation inputs.
- `generate_figures.py` lists, exports, or renders the accepted six-figure publication family.

Run each command with `--help` for its current options. See [the reproducibility guide](../docs/reproducibility.md) for examples and limitations.
